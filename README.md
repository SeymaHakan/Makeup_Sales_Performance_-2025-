💄 Makeup Sales Data Analysis (MySQL)
📌 Project Overview

In this project, I analyzed the Makeup Sales Dataset 2025 using MySQL. My goal was to perform data cleaning, explore the dataset, and obtain meaningful business insights.

📂 Dataset

The dataset includes:

Sales transactions of makeup products
Brand, product type, country information
Sales channel and payment method
Number of units sold and revenue
🔧 Tools Used
MySQL
SQL (Data Cleaning and Analysis)
🔍 Analysis Performed
1. Data Discovery
Dataset examined
Total number of records counted
2. Data Cleaning
Missing values ​​checked

3. Business Analysis
Top performing brands by revenue
Best-selling product types
Revenue by country
Sales channel performance
Monthly revenue trends
📊 Key Findings
I observed through analysis that some brands generated significantly higher revenue than others.
Certain product types dominate total sales volume.
Revenue varies between countries.
Sales channels show different performance levels.
Monthly trends helped me identify seasonal patterns.
